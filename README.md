# cobalt-orca

Pagine di appoggio ai calcoli ORCA su complessi di Co(II) con leganti canforati chirali.
Ogni composto ha una sottocartella con un `index.html` autosufficiente (immagini e
coordinate incorporate, nessuna connessione esterna).

    index.html              indice dei composti
    cotfc2bipy/index.html   [Co(tfc)2(bipy)] - 6 conformeri, popolazioni DeltaG
    robots.txt

Sito: https://g-pescitelli.github.io/cobalt-orca/

Materiale di lavoro, non ancora pubblicato. Le pagine contengono
`<meta name="robots" content="noindex,nofollow">`.
